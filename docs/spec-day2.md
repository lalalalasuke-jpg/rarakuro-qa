## 3. 作中タイトル「スイカゲーム v2.1」の正しい仕様

バグが無いときの動き。プレイヤーが読む「仕様メモ」と同じ内容。

### 画面

| 場所 | 内容 |
|---|---|
| タイトル | SUIKA GAME |
| バナー | 「秋の味覚フェア　11/1 - 11/7」 |
| スコア | 左上「SCORE N」 |
| NEXT | 右上に次の果物 |
| 箱 | 左右の壁と底。上のほうに赤いライン |
| 盤面の下の文 | 「同じ果物をくっつけて、大きな果物にしよう！」 |

### 操作

- 箱の上で指（マウス）を動かすと、持っている果物が左右に動く。真下に落下ガイドの線
- 指を離す（クリックを離す）と落ちる。次の果物は 0.6 秒後に出てくる
- 箱の**左端から右端まで、どこにでも落とせる**（果物が壁にめり込まない範囲で）

### ルール

| 項目 | 仕様 |
|---|---|
| 果物 | 11種類（小さい順）: さくらんぼ・いちご・ぶどう・デコポン・かき・りんご・なし・もも・パイナップル・メロン・スイカ |
| 合体 | 同じ果物がくっつくと、1つ大きい果物になる（スイカ同士は合体しない） |
| 違う果物 | くっつかずに転がる |
| 最初に出る果物 | さくらんぼ・いちご・ぶどうのどれか（ランダム） |
| NEXT | 次に出てくる果物が表示され、そのとおりの果物が出てくる |
| 底 | 落ちた果物は大きく跳ねない |
| ゲームオーバー | 果物が赤いラインを超えたまま（ほぼ止まった状態で）1.5 秒たつ |
| ゲームオーバー画面 | 「GAME OVER」「SCORE N」「報酬：どんぐり ×N」「もう一度あそぶ」 |

### スコアと報酬

| 項目 | 仕様 |
|---|---|
| 合体の点数 | できた果物の段階×10点（いちご＝20、ぶどう＝30、デコポン＝40、かき＝50 …） |
| コンボ | 前の合体から 1.2 秒以内に合体するとコンボ。点数が×2、×3…（「COMBO xN」と表示） |
| 【イベント】かきボーナス | 期間中、かきを作るとボーナス＋50点（かきを作ると合計 +100） |
| 点数の表示 | 合体するたびに、その場所に「+N」が出る |
| 【イベント報酬】どんぐり | ゲームオーバー時、スコア500点ごとに1個（例: 820点 → 1個、1200点 → 2個） |

## 4. バグ候補（14個）

2日目は、この14個から毎回ランダムに3つが仕込まれる。ただし **group が同じバグ（同じ場所のバグ）は同じ日に重ならない**。

| group | バグ |
|---|---|
| banner（バナーの文字） | SK-01・SK-11・SK-12 |
| reward（どんぐり） | SK-07・SK-14 |

SK-05（かきのボーナス）と SK-13（デコポン→りんご）は重なることがある。SK-13 があると、かきが作られなくなるので SK-05 が見つけにくくなる（**影響範囲**の例としてあえて残している）。

### 一覧

| ID | 種類 | 内容 | 起こし方 | 症状 |
|---|---|---|---|---|
| SK-01 | 見た目 | バナーの誤字 | ゲーム画面を見る | 「秋の味**角**フェア」 |
| SK-02 | 見た目 | NEXT と違う果物が出る | 果物を落として、次の果物を NEXT と見比べる | NEXT とは違う果物が出てくる |
| SK-03 | 挙動 | 右の壁ぎりぎりで箱の外に落ちる | 右の壁ぎりぎりまで寄せて落とす | 持っている果物が右の壁からはみ出し、落とすと箱の外へ |
| SK-04 | 挙動 | いちごとぶどうが合体する | いちごとぶどうをくっつける | デコポンになる |
| SK-05 | 仕様違い | かきのボーナスが入らない | かきを作る | +100 ではなく +50 |
| SK-06 | 仕様違い | コンボで点数が倍にならない | 1.2 秒以内に続けて合体 | COMBO と出るのに点数が普通と同じ |
| SK-07 | 仕様違い | どんぐりが1000点ごと | 500点以上でゲームオーバー | 例: 820点で0個 |
| SK-08 | 挙動 | 左の壁ぎりぎりまで寄せられない | 左の壁ぎりぎりまで寄せようとする | 壁から少し離れたところで止まる |
| SK-09 | 挙動 | 底の真ん中だけ跳ねる | 箱の真ん中あたりに落とす | トランポリンのように大きく跳ね返る |
| SK-10 | 挙動 | ぶどうに当たるとくっつく | ぶどうに別の果物をぶつける | 当たった果物がその場で止まって動かなくなる |
| SK-11 | 見た目 | バナーの文字が表示されない | ゲーム画面を見る | バナーが空っぽ |
| SK-12 | 見た目 | バナーの文字化け | ゲーム画面を見る | 「遘九縺ｮ蜻ｳ隕壹ヵ繧ｧ繧｢」 |
| SK-13 | 挙動 | デコポンを合体させるとりんご | デコポン同士を合体 | かきを飛ばしてりんご |
| SK-14 | 仕様違い | どんぐりがもらえない | 500点以上でゲームオーバー | いつも0個 |

### 「見た」と「修正確認」になる操作

そのバグが起きるはずの操作をしたとき、バグが**出たら「見た」**、**出なかったら（直っていれば）「修正確認」**になる。

| ID | 判定される操作 |
|---|---|
| SK-01・11・12 | そのプレイで最初に箱の上を触った（＝画面を見ている） |
| SK-02 | 果物を落として、次の果物が出てきた |
| SK-03 | 右の壁ぎりぎり（果物が壁に触れる位置）まで寄せて落とした |
| SK-04 | いちごとぶどうがぶつかった |
| SK-05 | かきができた |
| SK-06 | コンボ（2回目以降）で合体した |
| SK-07・14 | 500点以上でゲームオーバーになった |
| SK-08 | 左の壁から 70 ピクセル以内まで寄せようとして落とした |
| SK-09 | 果物が底の真ん中（横 120 ピクセル）に当たった |
| SK-10 | ぶどうに別の果物がぶつかった |
| SK-13 | デコポン同士が合体した |

## 5. 報告書の選択肢（スイカゲーム）

流れ・ページ・判定・採点は [1日目の仕様書](spec-day1.md) の6〜9章と同じ。選択肢は14個のバグ候補の正解すべて＋ダミー。

| 項目 | ダミー |
|---|---|
| どこで | タイトル画面／ショップ画面 |
| 再現手順 | 果物を長押しする／画面を2本指でタップする |
| 何が | 果物の色／ゲームオーバーのライン |
| 期待する動き | スイカを作るとボーナス＋100点／果物は落としたところで止まる |
| 実際の動き | 果物が落ちてこない／スコアが減る |

選択肢の数（重なりをまとめたあと）: どこで 10／再現手順 13／何が 12／期待する動き 12／実際の動き 16／重要度 3

## 9. テストの観点（メモ）

- 14個のバグそれぞれ: 起こせるか／報告して直るか／修正確認できるか
- 同じ group のバグが同じ日に出ないか（バナー2つ、どんぐり2つが同時に出ない）
- SK-05 と SK-13 が同じ日に出たとき、かきのボーナスをどう確かめるか（影響範囲）
- 点数の計算が仕様どおりか（「+N」の表示、コンボ、かきボーナス、どんぐりの数）
- 左右の壁ぎりぎりまで寄せられるか（正しい動き）
- 1日目 → 2日目 の切り替え、ブラウザを開き直したときに2日目から始まるか
- スマホのタップで果物を動かして落とせるか、報告書のボタンが押せるか
