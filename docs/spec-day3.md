## 3. リリースノート

仕様メモの「v1.4 で直したこと・変えたこと（リリースノート）」に書いてあること。

- 1種類だけ絵柄の差し替えが漏れていた不具合を修正
- 素早くタップすると3枚めくれる不具合を修正
- クリア報酬の数が仕様と違う不具合を修正
- ペアがそろった時に手数が増えない不具合を修正
- イベント期間の表示が間違っていた不具合を修正
- 同じカードを2回タップすると1枚でペアになる不具合を修正
- 違う絵柄がペアになる不具合を修正
- 報酬の名前とルール説明の文言を、イベントごとに変えられるように変更（マスタ化）
- タイマーと、60秒以内クリアのボーナスを追加
- もみじの特効を追加

**狙い**: 「直した」と書いてある所が本当に直っているか（回帰テスト）、直した所の近くが壊れていないか（影響範囲）を、プレイヤーが自然に試したくなるようにする。

## 5. 報告書の選択肢

選択肢は11個のバグ候補の正解すべて＋ダミー。ヒントの「期待する動き」は「仕様メモとリリースノートを見てみよう」になる。

| 項目 | ダミー |
|---|---|
| どこで | タイトル画面／仕様メモ |
| 再現手順 | カードを長押しする／ゆっくり1枚ずつめくる |
| 何が | カードの裏面／ペア数の表示 |
| 期待する動き | ペアがそろったカードは消える／クリアで「もみじメダル」×10 |
| 実際の動き | カードがめくれない／タイマーが動かない |

## 9. テストの観点（メモ）

- 11個のバグそれぞれ: 起こせるか／報告して直るか／修正確認できるか
- リリースノートの修正（1日目の7個）が、バグが出ていない日には本当に直っているか（回帰テスト）
- タイマー: 最初の1枚で動き出す／クリアで止まる／もみじで5秒戻る
- 60秒ちょうど・60秒すぎのクリアのメダル数
- AU-08 のカードの裏面が他と同じか（裏面で見分けられないこと）
- 文字化けしたルール説明が画面からはみ出さないか
- 2日目の結果 →「3日目へ」→ 3日目、ブラウザを開き直したときに3日目から始まるか
